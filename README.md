
# 🏭 Factory Code

**Build your factory. Automate everything. Learn to code.**

Factory Code is an indie 2D pixel art factory-building game where players learn programming through automation and creativity.

## 🎮 About the Game

Start with an empty plot of land and build your own industrial empire.

Construct machines, connect conveyor belts, automate production and use programming to control your factory.

## ⚙️ Planned Features

- 🏗️ Free factory construction
- 🚚 Conveyor belt systems
- 🤖 Programmable robots
- ⚙️ Automated production
- 💻 Interactive programming lessons
- 📈 Progressive learning system

## 📚 Learn Programming

The game aims to teach:

- Variables
- Conditions (if / else)
- Loops (for / while)
- Functions
- Automation logic

## 🛠️ Development

- Engine: Godot 4
- Language: GDScript
- Visual style: 2D Pixel Art
- Platform: Planned for PC and mobile
